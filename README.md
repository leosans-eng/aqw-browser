# AQW Browser

A browser client for [AdventureQuest Worlds](https://www.aq.com/). It loads the official game with [Ruffle](https://ruffle.rs/) and relays HTTP and game sockets to Artix’s servers.

This is an **unnoficial port** that runs it on a Browser, just like it did when Flash Player was around.

*AdventureQuest Worlds* and every asset belongs to *Artix Entertainment*.
